Browser clients speak the same binary protocol over WebSocket. Start the server with network.ws_listen = "127.0.0.1:17282" (or --ws), then open this page via any static file server (for example python3 -m http.server -d web 8080). For remote/HTTPS use a reverse proxy that terminates TLS (WSS). A Rust/WASM client can reuse this transport later.
